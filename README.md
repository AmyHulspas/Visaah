# Visaah (3D visualization framework)
A modular C++ framework for real-time visualization, rendering and computational applications.

# How to install on Linux:
Install the required libraries onto your Linux system

`sudo apt update`

`sudo apt install cmake`

`sudo apt install doxygen`

`sudo apt install libgtest-dev`

`sudo apt install g++ libx11-dev libxi-dev libgl1-mesa-dev libglu1-mesa-dev libxrandr-dev libxext-dev libxcursor-dev libxinerama-dev libxi-dev`


Fork/clone this respository:
` git clone https://github.com/AmyHulspas/Visaah.git `

# How to run and use on Linux:
Build the framework library: 
Configure CMake: `cmake -S . -B build`

Generate the build files: `cmake --build build`

Run the demo `./build/demo #Run the demo`
